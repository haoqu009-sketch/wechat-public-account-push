# 附件处理升级

## 当前状态

这是待部署版本的操作说明，不代表服务器已升级。2026-10-20本地完成附件流程与回归测试；远程检查因权限审批服务额度不足未执行，因此尚未核查或安装服务器文档/OCR依赖，也未切换线上版本。

## 处理与保守边界

- XLS/XLSX：原生工作表单元格、明确合并区域、物理行号。
- DOCX：ZIP/XML离线读取，保留横向/纵向合并单元格。不运行宏、不访问外部关系。修订、嵌套表格、内嵌图片保留疑点，不默认完整。
- 原生PDF：pdfplumber依据实际表格线与单元格矩形恢复行列。只在表头、岗位、学历、专业列完整时生成岗位行。无框表、无表头续表、串列和缺格保留复核；不靠空格猜列。
- 旧版DOC：如有antiword可读取文字，仍是线索，不冒充完整表格。
- 图片/扫描PDF：可选本机Tesseract中文OCR，不调用付费API。结果始终是待复核线索；即使文字识别成功，也不会自动确认专业代码、日期、学历或岗位资格。每附件最多6页OCR，整个子进程90秒超时，超限明确报告。
- Word表外段落、PDF表外说明和Excel注释行保留为补充条件证据；适用范围不清时不得判为全部满足。

附件清单区分岗位材料、辅助报名材料、用途未定材料，并分别记录已解析、部分解析、排队、OCR待复核、下载失败。默认每公告8份、每来源24份附件下载预算，岗位材料优先；超限保留清单，按4小时窗口轮转，未完成不能计作完整覆盖。全局原文核验仍受60次请求预算约束。

`reports/attachment-status.json`是私有完整清单。网页只导出白名单字段，不导出文件路径、收件人、配置、文件内容和内部哈希。旧版不可变报告继续兼容。

解析缓存只复用相同文件内容和解析器代码版本的完整结果。每轮仍先请求官网下载；403不会因缓存变成成功。缓存最多100条、总计50MB，损坏时重新解析，不影响权威去重状态。

## 待部署验收步骤

1. 正常权限审批恢复后，通过既有Tailscale SSH检查Python、剩余内存、系统工具及当前定时任务；不开放公网22端口，不改变主站。
2. 在独立虚拟环境安装`requirements-documents.txt`。Word原生解析只用Python标准库。可选OCR需系统Tesseract及`chi_sim`、`eng`语言包；未安装或未验收前不要宣称已启用OCR。
3. 如需更换Python，在既有root私有环境文件中设置`RECRUITMENT_DOCUMENT_PYTHON`为虚拟环境Python的绝对路径。仅完成OCR实测后才设置`RECRUITMENT_OCR_ENABLED=true`。沿用非特权采集用户和现有512MB/50%CPU限制；不通过放宽服务沙箱解决依赖错误。
4. 在独立QA目录，用真实受限样本、Word/PDF样本跑附件与核验测试。必须检查实际提取内容，而不是只看退出码。确认OCR耗时/峰值内存适合机器；不足时保持关闭，不能把扫描件标为已核实。
5. 使用全局flock，备份当前release、私有state、pending、server-control、环境文件和招聘静态页面。先更新支持附件白名单的接收端，再更新采集端；旧报告无需重写。
6. 只运行现有refresh入口，不运行daily/send。回读公共latest与不可变快照，核对报告一致性、附件清单、岗位证据及旧ID，确认收件人/已发送记录、pending、server-control未变。
7. 保留07:30晨报、重试时间与网页刷新时刻。遇到失败回滚至发布前release/接收端/静态文件，不能清空去重状态。

## 手动补充受限原件

只在人工从官方页面合法下载到原件后使用，不绕过验证码或权限。以下命令应以采集用户执行，文件需可读，存储目录仍在私有state内：

```sh
RECRUITMENT_STATE_DIR=/var/lib/recruitment-collector/state \
  /opt/recruitment-reader/runtime/node/bin/node \
  /opt/recruitment-collector/current/recruitment/import-attachment.mjs \
  --url 'https://已批准的官方域名/原始附件地址.xlsx' \
  --file '/临时上传目录/官方原件.xlsx' --format xlsx
```

默认保存到`state/attachment-imports`。仅接受配置中已批准的官方HTTPS域名；校验内容哈希，30天后不再自动使用。下一轮官网附件失败时回放解析，始终标明手动补充，核验最多为partial，不能因此宣称官网当前文件、报名状态或个人资格已确认。官网恢复后优先当前官网下载结果。

## 未解决的外部限制

403/412、登录授权、失效证书、已撤回公告仍可能阻断获取。解析器不能替代合法下载权限。没有启用搜索付费服务、云OCR或大模型猜补条件；不能承诺任意格式、所有附件100%自动正确。
